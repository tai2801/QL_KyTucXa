# Contributing
1. Fork repo, tao nhanh `feature/<ten>`.
2. Bien dich va chay test truoc khi gui PR: `./run-tests.sh` (phai 0 FAIL).
3. Giu kien truc 3 lop: GUI/Console -> DormService -> DataStore. Khong goi file truc tiep tu GUI.
4. Dat ten class/bien co y nghia, comment o logic nghiep vu quan trong.
